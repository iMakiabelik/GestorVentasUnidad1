Descripción
Aplicación de consola en C# (.NET 8) que gestiona el inventario y las ventas diarias de una tienda local.
Requisitos e Instalación
- .NET 8.0 SDK
Clonar repositori
git clone <URL_DEL_REPOSITORIO>
Entrar a la carpeta
cd GestorVentasUnidad1
Compilar y ejecutar
dotnet run

Temas Implementados (Sin POO)
- Control de flujo (`if`, `switch`, `do-while`).
- Manejo de datos en memoria mediante listas (`List<T>`).
- Manejo seguro de entradas con `int.TryParse` y `decimal.TryParse`.
- Métodos estáticos auxiliares (`LeerEntero`, `LeerDecimal`, `CalcularFactura`, `ImprimirEncabezado`).
